# Diagnostic Evidence

This directory contains sanitized summaries of the hardware investigation.

## Available Documentation

| File | Description |
|---|---|
| `psk-session-summary.md` | Summary of the PSK mismatch and provisioning timeout |

## Raw Diagnostic Evidence

The original diagnostic files are retained in the researcher's local environment and are not included in this public repository.

This includes:

- Original PSK diagnostic log.
- Local library linkage information.
- Diagnostic revision information.

Raw logs may contain local paths, system information or other details that are unnecessary for public distribution.

## Evidence Policy

Published diagnostic summaries must:

- Preserve the technical meaning of the original observations.
- Avoid exposing personal or unnecessary system information.
- Distinguish observed behavior from interpretation.
- Avoid claiming successful operations when only a timeout was recorded.
- Include enough context for independent technical review.

## Important Limitation

The absence of raw logs in this repository does not mean the observations are independently reproducible from the published files alone.

Researchers interested in additional evidence may request further sanitized information.
